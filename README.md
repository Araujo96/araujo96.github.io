# Portfólio — Lucas Araújo

Site pessoal de desenvolvedor full stack: https://araujo96.github.io/

Página estática (um `index.html`, sem build), publicada pelo GitHub Pages a partir da branch `main`.

- Textos, projetos e links ficam no bloco **"CONTEÚDO EDITÁVEL"** no fim do `index.html`.
- Imagens dos projetos em `img/<projeto>/`, no formato 1920×1080 (WebP), com miniatura `-thumb` de 480×270.
- O `.gitignore` é uma lista de permissão: só sobe o que o site usa.

Para ver localmente, abra o `index.html` no navegador.
